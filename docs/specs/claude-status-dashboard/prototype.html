                토큰 사용량

                Claude를 얼마나 썼는지 보여 주는 두 가지 값이에요. 플랜 한도 사용률을 먼저 보고, 토큰 수는 자세히 볼 때 써요.

                5시간 한도62%
                주간 한도84%

                짧은 창(5시간)은 자주 비워지고, 긴 창(일주일)은 계속 쌓여요. 둘 중 하나라도 100%가 되면 작업이 멈춰요.

                쉽게 말하면

                Claude 구독 플랜에는 쓸 수 있는 양이 정해져 있어요. 휴대폰 데이터 요금제처럼 5시간 동안 쓸 수 있는 양과 일주일 동안 쓸 수 있는 양이 따로 있어요. 대시보드의 %는 그중 얼마나 썼는지예요.

                토큰은 Claude가 글을 읽고 쓰는 단위예요. 한글 한두 글자가 대략 토큰 하나예요. 내가 보낸 말(입력), Claude가 쓴 답(출력), 다시 읽으려고 저장해 둔 내용(캐시)이 모두 토큰으로 세어져요.

                같은 일도 어떤 모델에게 맡기느냐에 따라 한도가 줄어드는 속도가 달라요. 간단한 일은 Sonnet이나 Haiku에게 맡기면 한도를 아낄 수 있어요.

                Claude가 답 하나를 만들 때 함께 읽는 범위예요. 책상에 비유하면 이해하기 쉬워요.

                쉽게 말하면

                Claude는 자료를 펼쳐 둔 책상에서 일해요. 내가 보낸 메시지, Claude가 읽은 파일, 명령을 실행한 결과가 모두 책상 위에 쌓여요. 이 책상이 컨텍스트 윈도예요.

                책상 크기에는 한계가 있어요. 그리고 Claude는 답할 때마다 책상 전체를 다시 읽어요. 그래서 상관없는 자료가 많이 쌓이면 중요한 규칙을 놓치거나 고친 실수를 다시 하기도 해요.

                책상이 70% 넘게 찼다면 정리할 때예요. 다른 일로 넘어가면 /clear로 새로 시작하고, 같은 일을 이어 가야 하면 /compact로 요약 한 장만 남겨요.

                세션

                Claude와 나누는 대화 한 묶음이에요. 세션을 여러 개 열면 Claude에게 여러 일을 동시에 맡길 수 있어요.

                쉽게 말하면

                claude를 실행하거나 Desktop 앱에서 새 세션을 열면 대화 하나가 시작돼요. 이 대화 하나가 세션이에요. 세션마다 책상(컨텍스트 윈도)이 따로 있어요.

                일 하나에 세션 하나가 기본이에요. 버그를 고친 세션에서 새 기능을 이어 만들면, 상관없는 버그 기록이 책상에 남은 채 시작해요.

                오래 걸리는 일은 세션을 나눠 동시에 맡겨요. 한 세션이 일하는 동안 다른 세션에 다음 일을 맡기면 기다리는 시간이 줄어요. 같은 파일을 건드리는 일이라면 Worktree로 세션마다 폴더를 나눠요.

                CLI

                터미널에서 명령어로 쓰는 프로그램이에요. 내 PC에 설치하고 로그인해 둔 CLI는 Claude도 그대로 써요.

                나→터미널
                gh issue list                ←Claude

                Claude의 명령 실행 도구는 내 PC의 터미널을 써요. 그래서 내가 로그인한 계정 그대로 같은 명령을 실행해요.

                쉽게 말하면

                git, gh, vercel처럼 터미널에 입력해서 쓰는 프로그램을 CLI라고 해요. Claude는 내 PC의 터미널에서 명령을 실행할 수 있어서, 내가 설치한 CLI를 따로 연결하지 않아도 써요.

                같은 서비스에 CLI와 MCP 서버가 둘 다 있으면 CLI부터 써 보세요. CLI는 필요한 결과만 골라 받을 수 있어서 책상(컨텍스트 윈도)을 덜 차지해요.

                설치 안 된 CLI는 Claude도 못 써요. 강의 실습에 쓰는 CLI가 '없음'으로 보이면 먼저 설치하세요.

                MCP

                Claude에게 새 도구를 꽂아 주는 표준 규격이에요. USB-C처럼 규격에 맞춘 서버를 연결하면 Claude가 그 도구를 써요.

                Claude Code⇄ MCP ⇄ 브라우저 (playwright)GitHub데이터베이스

                서비스를 만드는 쪽이 MCP 규격에 맞춰 도구를 내놓고, Claude Code는 그것을 꽂아 써요.

                쉽게 말하면

                노트북에 USB-C 단자가 있으면 어느 회사 충전기든 꽂아 쓰죠. MCP도 같아요. 브라우저, GitHub, Notion 같은 서비스가 MCP 규격으로 도구를 내놓으면 Claude Code가 꽂아서 써요.

                연결한 MCP 서버는 쓰지 않아도 도구 설명이 책상에 미리 올라가요. 그래서 안 쓰는 서버를 많이 연결해 두면 컨텍스트 윈도를 그만큼 먼저 써요.

                Claude Desktop에서 연결한 커넥터(Google Calendar 등)는 계정에 저장돼서 이 대시보드에는 보이지 않아요.

                Memory

                Claude가 다음 대화에 쓰려고 스스로 적어 두는 메모예요. CLAUDE.md는 내가 쓰고, Memory는 Claude가 써요.

                쉽게 말하면

                일 잘하는 동료는 지적받은 걸 수첩에 적어 두고 다음 일 전에 펼쳐 봐요. Claude도 내가 바로잡은 말이나 내 작업 방식을 Memory에 적어 두었다가 새 세션에서 펼쳐 봐요.

                메모는 네 종류예요. 나에 대한 것(user), 내가 바로잡거나 좋다고 한 방식(feedback), 코드에 없는 진행 중인 일(project), 바깥 자료의 위치(reference)예요.

                MEMORY.md는 메모 목록이에요. 세션을 시작할 때 이 목록을 먼저 읽고, 각 메모는 필요할 때 열어 봐요. 틀린 메모가 있으면 지워 달라고 하면 돼요.
