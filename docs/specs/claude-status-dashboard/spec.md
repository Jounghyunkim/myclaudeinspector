# 내 Claude 현황 대시보드 첫 화면, 자세히 보기, 트렌드

Claude 설치 경로와 프로젝트 경로를 넣으면 토큰 사용량, 컨텍스트 윈도, 세션, 도구(CLI, MCP, Skills, CLAUDE.md, Memory)의 현황을 초보자용 설명과 함께 한 화면에 보여 준다. 내 사용 패턴에 맞는 추천 하나를 복사할 프롬프트와 함께 제시하고, 항목마다 강의 자료로 이어지는 자세히 보기 화면을 두고, 하루 한 번 남기는 스냅샷으로 세션과 도구의 변화를 보는 트렌드 화면을 둔다.

연결된 자료:
- [prototype.html](prototype.html) — 승인된 화면. 대시보드 1개, 트렌드 1개, 자세히 보기 8개의 배치, 항목 순서, 문구, 차트 모양, 상태(첫 진입, 경로 오류, 한도 값 없음, 스냅샷 1개), 좁은 화면에서 쌓이는 순서는 이 파일을 따른다. 데이터는 모두 예시다.
- [ui-composition](../../decisions/ui-composition.md) — 일반 UI는 공식 shadcn component로 구성하고 색은 semantic token으로만 표현한다. 차트와 타임라인은 이 계약의 custom UI 예외에 해당한다.
- [GLOSSARY.md](../../../GLOSSARY.md) — 토큰 사용량, 플랜 한도 사용률, 토큰 수의 정의.
- [PRODUCT.md](../../../PRODUCT.md) — 읽기 전용, PC 밖으로 데이터를 보내지 않음, 비밀 정보를 읽지 않음, 초보자용 설명, 복사할 다음 행동.

## 사용자에게 보이는 결과

1. 교육생이 경로 두 개를 넣고 `불러오기`를 누르면 한 화면에서 내 Claude의 현재 상태를 본다. 위에서부터 오늘의 추천, 플랜 한도 사용률과 컨텍스트 윈도, 토큰 수, 세션, 도구 순서다.
2. 모든 카드에 `이게 뭐예요?`가 있어서, 누르면 "이게 뭐예요?"와 "왜 중요해요?"가 초보자 말투로 펼쳐진다.
3. 추천은 하나만 보인다. 바로 복사해 Claude 입력창에 붙여 넣을 프롬프트가 함께 있다.
4. Skill, MCP 서버, CLAUDE.md, Memory 파일을 누르면 그 자리에서 소개나 내용을 볼 수 있다.
5. 각 카드와 도구 영역의 `자세히 보기`를 누르면 그 주제의 자세히 보기 화면으로 이동한다. 이 화면에는 쉬운 설명, 강의 그림, 내 상태, 복사할 명령, 관련 강의 링크가 있다.
6. `트렌드 보기`를 누르면 최근 14일 또는 30일 동안 세션 수, 70% 넘은 세션 비율, 동시 세션, 도구 수가 어떻게 바뀌었는지와 언제 무엇이 바뀌었는지를 본다.
7. 앱은 Claude 쪽 파일을 읽기만 한다. 설정을 바꾸는 일은 교육생이 프롬프트나 명령을 복사해 Claude에서 직접 한다.

## 승인된 범위

- 경로 입력과 불러오기. 첫 진입 상태와 경로 오류 상태가 있다.
- 오늘의 추천 1개와 복사 버튼
- 플랜 한도 사용률: 5시간·주간 미터, 초기화 시각과 남은 시간, 80% 표시, 값이 오래됐는지 안내, 값이 없을 때의 안내
- 컨텍스트 윈도: 이 프로젝트의 최근 세션 5개의 사용률 미터, 70% 적정선, 요약 숫자
- 토큰 수: 최근 7일·최근 4주 쌓은 막대 차트(입력, 출력, 캐시 쓰기), 툴팁, 표로 보기, 오늘 입력+출력·캐시 쓰기·캐시 읽기 숫자
- 세션: 요약 숫자 5개, PC에서 지금 열린 세션 목록, 오늘의 세션 타임라인(이 프로젝트), 최근 세션 표
- 도구: 요약 숫자 5개와 CLI, Skills, MCP, CLAUDE.md, Memory 다섯 영역을 탭 없이 한 화면에 표시
  - Skill과 MCP는 선택하면 소개 상자가 열린다.
  - CLAUDE.md와 Memory는 선택하면 줄 번호가 붙은 내용 보기가 열린다.
- 자세히 보기 8개: 토큰 사용량, 컨텍스트 윈도, 세션, CLI, MCP, Skills, CLAUDE.md, Memory
- 트렌드: 하루 한 번 스냅샷 저장, 기간 선택(최근 14일·30일), 세션 트렌드(요약 숫자와 차트 3개), 도구 트렌드(스파크라인 6개, 하루 Skill 사용 횟수, 변화 기록), 스냅샷 기록 표
- Claude Style 시각 언어(아래 제약 참고)

## 수용 기준

실제 PC의 `~/.claude`와 이 저장소를 경로로 넣고, 실행 중인 앱을 브라우저로 확인한다.

**경로와 상태**
- AC1. Claude 설치 경로의 기본값은 사용자의 `~/.claude`이다. 두 경로를 넣고 `불러오기`를 누르면 대시보드가 채워지고, 마지막으로 불러온 시각이 보인다.
- AC2. 없는 경로를 넣으면 경로 오류 안내가 보이고, 잘못된 입력란이 오류로 표시된다. 다른 카드는 채워지지 않는다.
- AC3. 경로를 넣기 전 첫 진입에서는 무엇을 넣어야 하는지 알려 주는 빈 상태가 보인다.

**토큰 사용량**
- AC4. 플랜 한도 사용률은 5시간과 주간 각각 %, 초기화 시각, 초기화까지 남은 시간을 보여 준다. 80% 이상인 쪽에는 아이콘과 "80% 넘음" 표시가 붙는다.
- AC5. 플랜 한도 값이 없으면 카드에 값이 없다는 안내와 `/usage`로 확인하는 방법이 보인다. 0%로 표시하지 않는다. 값이 있으면 언제 받아 온 값인지 함께 보인다.
- AC6. 토큰 수 차트는 대화 기록의 응답별 토큰을 일별(최근 7일)과 주별(최근 4주)로 더해 입력, 출력, 캐시 쓰기를 쌓아 보여 준다. 막대에 마우스를 올리거나 키보드로 고르면 그 기간의 값이 툴팁으로 나온다. `표로 보기`를 누르면 같은 값의 표가 나온다.
- AC7. 캐시 읽기는 차트에 쌓지 않고 옆의 숫자로만 보여 준다.

**컨텍스트 윈도와 세션**
- AC8. 컨텍스트 윈도 카드는 이 프로젝트의 최근 세션 5개를 보여 준다. 세션마다 이름, 사용률 %, 모델, 마지막 활동 시각이 있다. 70%를 넘은 세션은 다른 색과 "70% 넘음" 표시로 구분된다.
- AC9. 세션 카드의 지금 열린 세션 목록에는 PC에서 실행 중인 Claude Code 세션의 이름, 상태(작업 중/대기), 폴더, 앱(Desktop/CLI), 시작 후 지난 시간이 보인다. 화면을 열어 둔 동안 30초마다 다시 읽는다.
- AC10. 오늘 타임라인은 이 프로젝트의 오늘 세션을 시간축 위 막대로 보여 주고, 현재 시각 선이 있다. 진행 중인 세션은 현재 시각까지 이어진다. 막대를 가리키거나 키보드로 고르면 시간, 길이, 메시지 수, 모델, 컨텍스트가 나온다.
- AC11. 최근 세션 표에는 이 프로젝트 세션별 이름, 상태, 시작 시각, 길이, 메시지 수, 모델, 컨텍스트 %, 자동 압축 횟수, 브랜치가 있다.
- AC12. 요약 숫자는 지금 열린 세션 수, 오늘 세션 수, 이번 주 세션 수, 오늘 동시에 돌린 세션의 최대 개수, 이번 주 자동 압축 횟수다.

**도구**
- AC13. CLI 영역은 claude, git, gh, node, bun, vercel, supabase의 설치 여부와 버전을 보여 준다. 없는 것은 "없음"과 그 CLI가 무엇에 쓰이는지 한 줄 설명을 보여 준다.
- AC14. Skills 영역은 사용 횟수가 많은 순서의 막대와 아직 안 쓴 Skill 목록을 보여 준다. Skill을 고르면 이름, 설치 위치(프로젝트/사용자/플러그인), 사용 횟수, `SKILL.md` frontmatter의 `description` 원문, 파일 경로가 보인다. 긴 description은 3줄까지 보이고 `전체 보기`로 펼친다. description이 비어 있으면 그 사실과 왜 문제인지 안내한다.
- AC15. MCP 영역은 로컬 설정 파일에 있는 서버만 보여 준다. 서버를 고르면 연결 방식, 설정 위치, 실행 명령이 보인다. 알려진 서버면 한 줄 소개도 보이고, 모르는 서버면 실행 명령으로 찾아보라고 안내한다. Desktop 커넥터는 여기에 보이지 않는다는 안내가 있다.
- AC16. CLAUDE.md 영역은 이 프로젝트에 적용되는 CLAUDE.md 계열 파일(사용자 `~/.claude/CLAUDE.md`, 프로젝트 `CLAUDE.md`, `@`로 불러오는 파일)의 줄 수를 막대로 보여 준다. 파일을 고르면 줄 번호와 함께 내용이 보이고, `@`로 시작하는 줄은 강조된다.
- AC17. Memory 영역은 이 프로젝트의 `MEMORY.md`와 메모 파일 목록을 보여 준다. 각 메모에는 종류와 frontmatter의 description이 있다. 파일을 고르면 내용이 보인다.

**추천**
- AC18. 추천은 다음 순서로 처음 맞는 규칙 하나만 보여 준다.
  1. 플랜 한도 80% 이상 → 가벼운 모델로 바꾸기
  2. 최근 세션 중 컨텍스트 70% 넘은 세션 → `/clear` 또는 세션 나누기
  3. 아직 안 쓴 Skill → 써 볼 Skill 하나
  4. CLAUDE.md 합계가 약 200줄 넘음 → 절차를 Skill로 옮기기
  5. 해당 없음 → 아직 안 써 본 기능 하나
- AC19. 추천에는 그 근거가 된 내 값이 문장에 들어 있다. `프롬프트 복사`를 누르면 프롬프트가 클립보드에 들어가고 복사됐다는 안내가 잠깐 보인다.

**자세히 보기**
- AC20. 대시보드의 플랜 한도 사용률, 토큰 수, 컨텍스트 윈도, 세션 카드와 도구 다섯 영역, 지금 열린 세션 영역에서 각 주제의 자세히 보기로 이동할 수 있다. 자세히 보기에서는 `← 대시보드로`와 주제 칩으로 다른 주제로 이동할 수 있다.
- AC21. 자세히 보기마다 다음이 있다.
  - 한 줄 정의
  - 강의 그림 또는 도식
  - "쉽게 말하면" 설명
  - 대시보드에서 불러온 내 상태 값
  - 복사할 명령이나 프롬프트
  - 관련 강의 링크
  - 강의 링크는 docs.claude-hunt.com의 해당 lesson을 새 탭으로 연다. 그림 아래에는 출처 링크가 있다.
- AC22. 강의 그림을 불러오지 못하면 그 자리에 강의 페이지에서 볼 수 있다는 안내가 보이고, 나머지 내용은 그대로 보인다.

**경계와 화면**
**트렌드**
- AC27. 하루 중 처음 `불러오기`가 성공하면 그날의 스냅샷이 앱의 폴더(`~/.my-claude-inspector/snapshots/`)에 날짜별로 하나 남는다. 같은 날 다시 불러오면 그날 스냅샷을 새 값으로 바꾸고, 다른 날짜 스냅샷은 그대로 둔다. 대시보드 머리말에 오늘 스냅샷을 남겼는지 보인다.
- AC28. 대시보드 머리말의 `트렌드 보기`와 세션·도구 카드의 `트렌드 →`로 트렌드 화면에 가고, `← 대시보드로`로 돌아온다.
- AC29. 세션 트렌드는 이 프로젝트의 대화 기록으로 계산한다. 그래서 스냅샷을 남기기 전 날짜도 보인다.
  - 요약 숫자: 세션 수, 하루 평균 세션, 70% 넘은 세션 비율, 2개 이상 동시에 돌린 날 수, 최대 동시 세션
  - 고른 기간 바로 앞의 같은 길이 기간과 비교한 변화량이 보인다. 앞 기간 기록이 없으면 그렇다고 표시한다.
  - 차트: 하루 세션 수(막대), 70% 넘은 세션 비율(최근 7일 비율 선과 그날 비율 점), 하루 최대 동시 세션(막대)
  - 막대나 날짜를 가리키거나 키보드로 고르면 그날의 값이 툴팁으로 나온다.
- AC30. 도구 트렌드는 스냅샷끼리 비교한다.
  - 스파크라인 6개: CLI 설치 수, MCP 서버 수, Skill 설치 수, 한 번이라도 쓴 Skill 수, CLAUDE.md 줄 수, Memory 메모 수. 각각 지금 값과 기간 첫 스냅샷 대비 변화가 있다.
  - 하루 Skill 사용 횟수 막대 차트가 있다.
  - 변화 기록에는 날짜별로 무엇이 추가·삭제되거나 몇 줄 늘었는지가 최신순으로 나온다.
- AC31. 스냅샷이 오늘 하나뿐이면 도구 트렌드 자리에 "아직 비교할 스냅샷이 없어요"와 내일 다시 열면 보인다는 안내가 나온다. 세션 트렌드는 그대로 보인다.
- AC32. 스냅샷 기록 표는 고른 기간의 날짜별 세션 수, 70% 넘은 세션 수, 동시 최대, CLI, MCP, Skill 설치, Skill 씀, CLAUDE.md 줄 수, Memory 수를 최신순으로 보여 준다. 스냅샷이 없는 날의 도구 값은 "–"이다. 이 표가 트렌드 차트의 표 보기 역할을 한다.

**경계와 화면 (이어서)**
- AC23. 앱을 쓰는 동안 Claude 설정 파일, Skill, MCP 설정, CLAUDE.md, Memory 중 어떤 파일도 바뀌지 않는다. 앱이 쓰는 파일은 앱 폴더의 스냅샷뿐이다. 앱에는 설정을 바꾸는 버튼이 없다.
- AC24. 앱은 `~/.claude/sessions/`의 `.key` 파일, 로그인 정보, 토큰, API 키를 읽지 않는다. 읽은 데이터를 PC 밖으로 보내지 않는다. 강의 그림을 불러오는 요청에는 사용자 데이터가 실리지 않는다.
- AC25. 넓은 화면, 768px, 390px에서 가로로 넘치는 곳이 없다. 표처럼 넓은 내용은 그 영역 안에서 가로로 스크롤된다.
- AC26. 대시보드는 넓은 화면을 빈틈없이 채운다. 내용 폭은 최대 1760px이다.
  - 1280px 이상: 경로 입력이 제목 옆에 놓이고, 오늘의 추천, 플랜 한도 사용률, 컨텍스트 윈도가 한 줄에 셋 놓인다.
  - 1440px 이상: 토큰 수와 세션이 한 줄에 나란히 놓이고, 같은 줄의 카드는 높이가 같다. 토큰 수 차트는 카드 높이에 맞게 늘어난다. 도구 다섯 영역은 한 줄에 다섯 칸으로 놓인다.
  - 1280px보다 좁으면 승인된 2열·1열 배치로 쌓인다.

## 확정된 제약과 근거

- **토큰 사용량은 플랜 한도 사용률을 먼저, 토큰 수를 자세한 정보로 보여 준다.** 교육생에게 중요한 것은 작업이 끊길지 여부라서다. (사용자 확정, GLOSSARY.md)
- **컨텍스트 윈도는 프로젝트 최근 세션 5개, 70% 기준이다.** PRODUCT.md의 성공 신호인 "컨텍스트 70% 유지"와 같은 기준을 화면에 보여 주기 위해서다. (사용자 확정)
- **추천은 하나, 규칙 순서는 AC18과 같다.** 작업이 끊길 위험이 가장 크므로 한도부터 본다. (사용자 확정)
- **CLI 목록은 강의에서 쓰는 7개와 버전이다.** (사용자 확정)
- **도구는 탭 없이 한 화면에 모두 보인다.** (사용자 확정)
- **대시보드는 넓은 화면을 채워 한눈에 보이게 한다.** 배치는 AC26과 같다. (사용자 확정)
- **세션과 도구는 하루 단위 스냅샷으로 트렌드를 본다.** (사용자 확정)
  - 스냅샷은 Claude 폴더가 아닌 앱 자신의 폴더에 저장한다. Claude 설정은 읽기만 한다는 경계를 지키면서 변화 기록을 남기기 위해서다.
  - 스냅샷에는 화면에 보이는 숫자와 이름(Skill·MCP·파일 이름, 줄 수)만 담는다. CLAUDE.md·Memory 본문, 대화 내용, 비밀 정보는 담지 않는다.
- **세션 현황을 함께 모니터링한다.** 지금 열린 세션은 PC 전체, 타임라인과 표는 이 프로젝트 기준이다. (사용자 확정)
- **Skill 소개는 `SKILL.md` frontmatter의 description 원문이다.** MCP 설정 파일에는 설명 칸이 없다. 그래서 MCP는 실행 명령과 알려진 서버의 짧은 소개로 대신하고, 서버를 실행해서 정보를 받지 않는다. 읽기 전용 경계를 지키기 위해서다. (사용자 확정, 근거는 로컬 설정 파일 구조 확인)
- **CLAUDE.md와 Memory는 내용 전체를 보여 준다.** 학습에 도움이 되기 때문이다. (사용자 확정)
- **자세히 보기는 주제 8개이고, 설명은 강의 자료의 비유(책상, 업무 매뉴얼, 수첩, USB-C)를 쉬운 말로 다시 쓴다.** 강의 문장을 그대로 옮기지 않는다. (사용자 확정)
- **시각 언어는 Claude Style이다.** 근거는 [mr5pm-public/claude-style-obsidian](https://github.com/mr5pm-public/claude-style-obsidian)의 `claude-style.css`이고, 현재 shadcn preset(lime, Outfit/DM Sans)을 대체한다. (사용자 확정)
  - 어두운 배경 `#1a1a1a`, 카드 `#1e1e1e`, 테두리 `#333`
  - 강조색 테라코타 `#c96442`
  - 본문 글꼴 북크고딕(없으면 맑은 고딕), 코드 SF Mono
  - 넓은 자간(0.06em)과 설명문 줄간격 2
  - 바깥 테두리 없는 표
  - 원본에 어두운 화면만 있으므로 밝은 테마는 두지 않는다.
  - Obsidian 전용 선택자와 `!important`는 옮기지 않고, 색·글꼴·간격을 semantic token과 component 스타일로 옮긴다. ui-composition 계약을 지키기 위해서다.
- **차트 색은 입력 `#3987e5`, 출력 `#d95926`, 캐시 쓰기 `#199e70`이다.** `#1e1e1e` 배경에서 색각 이상과 대비 검사를 통과했다. 두 계열 이상인 차트에는 범례를, 차트에는 표 보기를 둔다. 글자는 계열 색을 쓰지 않는다.

## 가정 (바꿀 수 있음)

- 플랜 한도 "높음"의 기준은 80% 이상이다.
- CLAUDE.md "너무 김"의 기준은 합계 약 200줄이다.
- 모델별 컨텍스트 윈도 크기는 모델의 기본값을 쓴다. 사용률은 세션 마지막 응답의 입력 쪽 토큰 합을 그 크기로 나눈 값이다.
- 플랜 한도 사용률은 `~/.claude.json`에 Claude Code가 저장해 둔 최근 값을 읽는다. 그 값을 받아 온 시각을 함께 보여 준다.
- 지금 열린 세션은 `~/.claude/sessions/*.json`의 상태 파일로 판단한다. 상태 파일이 남아 있어도 해당 프로세스가 없으면 열린 세션으로 세지 않는다.
- 동시 세션 수는 이 프로젝트 오늘 세션의 시작부터 마지막 활동까지 구간이 겹치는 최대 개수다.
- 자동 압축 횟수는 대화 기록에 남은 압축 경계 기록의 개수다.
- Skill 사용 횟수와 마지막 사용 시각은 `~/.claude.json`의 Skill 사용 기록을 쓴다.
- 오늘 타임라인 축은 오전 9시–오후 6시다. 그 밖의 세션이 있으면 축을 넓힌다.
- 알려진 MCP 서버 소개는 앱에 넣어 둔 짧은 목록으로 제공한다. 처음에는 강의에 나오는 서버만 넣는다.
- 강의 그림은 docs.claude-hunt.com에서 바로 불러온다.
- 스냅샷은 그날 처음 불러올 때 자동으로 남기고, 따로 누르는 버튼은 없다. 저장 위치는 `~/.my-claude-inspector/snapshots/<프로젝트 폴더 이름을 바꾼 값>/YYYY-MM-DD.json`이다. 프로젝트마다 따로 쌓아 여러 프로젝트를 번갈아 열어도 섞이지 않게 한다.
- 스냅샷은 지우지 않고 계속 쌓는다. 기간은 최근 14일(기본)과 30일만 고를 수 있다.
- 70% 넘은 세션 비율의 선은 최근 7일 누적 비율이다. 하루 비율은 세션 수가 적어 크게 흔들리기 때문이다.
- 세션은 시작한 날짜에 센다.
- 변화 기록은 이웃한 두 스냅샷을 비교해 만든다.

## 범위 밖과 이유

- **Claude 설정을 직접 바꾸는 기능:** Skill 설치·삭제, MCP 연결, 모델 변경을 앱에서 하지 않는다. PRODUCT.md의 읽기 전용 경계 때문이다.
- **Desktop 커넥터 목록:** 계정에 저장되어 로컬 파일에 없다.
- **MCP 서버를 실행해서 정보를 받는 것:** 읽기 전용 경계 때문이다.
- **Skill description 번역:** 요청되지 않았다.
- **밝은 테마:** 선택한 스타일이 어두운 화면만 정의한다.
- **원격 서버 접속:** 아래 미뤄 둔 결정 참고.
- **보안 하드닝, 엣지케이스·성능 방어:** AGENTS.md의 검증·리뷰 예산에 따라 범위 밖이다.

## 미뤄 둔 결정

- **원격 서버 형태 지원:** 원격 서버만으로는 교육생 PC의 Claude 설정을 읽을 수 없어서, 지원하려면 PC 쪽 구성 요소가 필요하다. 이번에는 localhost에서만 동작한다.
  - 다시 볼 때: 이 첫 화면이 배포된 뒤 교육생이 다른 기기에서 보고 싶다는 요청이 나오면 다시 정한다. 추적 issue는 아직 없다.

## 남은 위험

- **비공개 값 의존:**
  - `~/.claude.json`의 한도 값과 Skill 사용 기록, `~/.claude/sessions/`의 상태 파일, 대화 기록 형식은 Claude Code의 공개 문서에 없는 내부 형식이다.
  - 업데이트로 이름이나 위치가 바뀌면 해당 카드가 비거나 틀린 값을 보여 줄 수 있다.
  - 값이 없을 때 0으로 보이지 않고 "값 없음"으로 보이는 것(AC5)이 최소 방어선이다.
- **오래된 한도 값:** 플랜 한도 값은 Claude Code가 마지막으로 받아 둔 값이라 실제보다 늦을 수 있다. 받아 온 시각을 보여 줘서 판단을 돕는다.
- **강의 그림:**
  - 그림을 강의 사이트에서 바로 불러오므로 인터넷이 없으면 그림이 보이지 않는다(AC22).
  - 강의 사이트의 그림 주소는 빌드마다 바뀔 수 있어, 주소가 바뀌면 그림이 깨진다.
  - 강의 자료를 앱에 표시해도 되는지 강의 제공자의 허락을 확인하지 않았다.
- **세션 이름:** 상태 파일과 대화 기록의 세션 이름이 비어 있으면 "(이름 없는 세션)"으로 보인다.
- **글꼴:** 북크고딕이 없는 PC에서는 맑은 고딕으로 보여 원본 스타일과 느낌이 다르다.
- **비는 스냅샷:** 앱을 열지 않은 날은 스냅샷이 없다. 그날 도구 값은 비고, 변화 기록은 다음 스냅샷에 몰아서 나온다. 세션 트렌드는 대화 기록에서 계산하므로 영향이 없다.
- **스냅샷 형식 변경:** 앱이 업데이트되어 스냅샷 형식이 바뀌면 예전 스냅샷을 읽지 못할 수 있다.

## Post-release check

- 측정: `docs/specs/claude-status-dashboard/checks/context-over-70.mjs` — 사용자 `~/.claude/projects/<프로젝트>/`의 대화 기록을 읽는다. 릴리스 날짜를 인자로 받아 전·후 14일의 세션 수, 70% 넘은 세션 수, 비율을 출력하고, 기준을 만족하면 `PASS`, 아니면 `FAIL`을 출력한다.
